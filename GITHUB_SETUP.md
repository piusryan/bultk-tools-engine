RYAN - Bulk Tools Engine: A modern desktop application built with Python & PySide6 that handles bulk archiving (ZIP/TAR.GZ), unarchiving, document-to-PDF workflows, and PDF merging — all in one sleek dark-themed interface with cross-platform (Windows/Linux) executable support via PyInstaller.
